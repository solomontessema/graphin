# Graphin for Windows

The desktop version of Graphin. It is the same application as the web version, running on this computer:

- The interface is the same React app, shown in its own window (Tauri, using the WebView2 control that Windows already has).
- The engine is the same PHP code, run from a PHP runtime bundled inside the app. It listens only on `127.0.0.1`.
- The data is one SQLite file in the app-data folder (`%APPDATA%\com.ionnova.graphin\graphin.sqlite`). It has no login and no users table.
- It is independent of the web version. Nothing is synced between them.

## Build

You need:

- Node.js and npm
- Rust (`rustup`, stable MSVC toolchain). Install it from https://rustup.rs
- Visual Studio Build Tools with the "Desktop development with C++" workload (Tauri needs the MSVC linker)
- A PHP 8.x thread-safe build for Windows with `php_pdo_sqlite.dll` and `php_mbstring.dll`. XAMPP's `C:\xampp\php` works. Set `GRAPHIN_PHP_DIR` if yours is somewhere else.
- Composer dependencies in the project root (`composer install`)

Then, from this folder:

```powershell
npm install
npm run dev      # run the app in a development window
npm run build    # build the installer
```

`npm run build` and `npm run dev` first build the web app, then copy the app, the PHP code, the SQLite schema, and the PHP runtime into `src-tauri/bundle`. The installer is written to `src-tauri/target/release/bundle/nsis/`.

## Using the desktop app with the browser extension

The desktop app listens on `http://127.0.0.1:8765` when that port is free. Choose "Graphin desktop" in the extension's settings to save links there.

## Files

| Path | What it is |
|---|---|
| `scripts/prepare-bundle.mjs` | Builds the web app and gathers the files the desktop app ships with |
| `src-tauri/src/main.rs` | The launcher: starts PHP, waits for it, opens the window, stops PHP on exit |
| `src-tauri/tauri.conf.json` | App name, identifier, icon, and bundled resources |
| `src-tauri/bundle/` | Generated by the prepare script. Not in source control. |
| `../schema-sqlite.sql` | The SQLite schema, applied automatically the first time the database is used |
